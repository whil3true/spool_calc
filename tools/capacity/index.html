Почему результат ориентировочный

Для монофильной лески и флюорокарбона расчёт опирается на диаметр и длину с маркировки шпули. Для плетёнки заявленный диаметр хуже описывает реальную укладку, поэтому результат показывается диапазоном.

Если вы пытаетесь подобрать метраж только по размеру катушки 1000, 2500 или 3000, этого недостаточно: используйте маркировку конкретной шпули.
