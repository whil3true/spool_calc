Сколько бэкинга намотать?

Укажите данные с маркировки шпули, вашу основную леску и диаметр бэкинга. Результат будет диапазоном, потому что реальная укладка никогда не обязана уважать красивую цифру.

1. Маркировка шпули

Перепишите одну или несколько строк вида «диаметр / длина», например 0,18 мм / 170 м.

2. Основная леска или шнур

Тип основной лески

Для плетёного шнура вводите только заявленный производителем диаметр в миллиметрах (мм). Размер PE и прочность в фунтах (lb) не переводятся в диаметр.

3. Какой будет бэкинг?

Для более предсказуемой оценки используйте обычную монофильную леску известного диаметра.

Как проверить без гадания

  1. Если есть запасная шпуля сопоставимой вместимости, сначала намотайте на неё всю основную леску.
  2. Добавляйте бэкинг поверх основной лески до нужного уровня у бортика.
  3. Перемотайте всё на рабочую шпулю: бэкинг окажется снизу, основная леска сверху.
  4. Оцените уровень заполнения по инструкции вашей катушки; универсального зазора для всех шпуль нет.

Если подходящей запасной шпули нет, расчёт используйте как стартовую длину, а финальный уровень проверяйте физически.
